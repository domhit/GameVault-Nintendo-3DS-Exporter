# Third-party software

## libctru
- https://github.com/devkitPro/libctru
- zlib-style permissive license
- Provides 3DS runtime and AM service APIs including `AM_GetTitleCount`, `AM_GetTitleList`, and `AM_GetTitleInfo`.

## FBI
- https://github.com/Steveice10/FBI
- MIT License
- Reference implementation for installed-title management on 3DS. No FBI binary is bundled.

## 3DS App Manager
- https://github.com/Marcogn/3DSAppManager
- MIT License
- Modern reference confirming installed-title enumeration on CFW/homebrew systems. No binary is bundled.
